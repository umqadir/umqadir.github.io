# umqadir.github.io

Personal site of Uzair Qadir, served by GitHub Pages.

`content.md` is the single source of truth. `build.py` renders it into `index.html` via `template.html` (a GitHub Action does this on every push to `content.md`), and a workflow in [umqadir/umqadir](https://github.com/umqadir/umqadir) pulls the same file into the profile README daily. Edit `content.md`; everything else follows.
